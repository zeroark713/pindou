# 🎨 拼豆像素图生成器 v1.1

> 上传图片 → 一键转换为带色号的拼豆点阵图
> 支持裁剪 / 修豆块 / 镜像 / 文字拼豆 / 多色卡 / 高清导出 / 响应式 UI

## ✨ 功能

- 📷 **三种视图**：效果图 / 原图 / 图纸（带坐标）
- 🎨 **5 套色卡**：MARD 漫漫 / 咪露 / Perler / Hama / Artkal
- ✂️ **图片裁剪** v1.1：选区拖动 / 缩放 / 比例约束 / 还原原图
- 🖌 **修豆块**：点击格子换色，支持撤销
- ⇄ **左右镜像**
- ⬜ **去除白底**
- 📝 **文字拼豆**：输入文字生成字符拼豆图
- 💾 **高清导出** v1.1：2x 超清 PNG，每格带完整色号（H/P/A/M/HM），下方附统计表（斑马纹 + 表格线 + 自适应列数）
- 📐 **自适应豆板**：29×29 ~ 300×300，预设 6 种常用规格
- 📱 **响应式 UI**：手机 / 平板 / 桌面三档适配

## 🚀 本地使用

直接双击 `index.html`，或：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```
