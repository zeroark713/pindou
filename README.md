# 🎨 拼豆像素图生成器

> 上传图片 → 一键转换为带色号的拼豆点阵图
> 支持修豆块 / 镜像 / 文字拼豆 / 多色卡 / 响应式 UI

## ✨ 功能

- 📷 **三种视图**：效果图 / 原图 / 图纸（带坐标）
- 🎨 **5 套色卡**：MARD 漫漫 / 咪露 / Perler / Hama / Artkal
- 🖌 **修豆块**：点击格子换色，支持撤销
- ⇄ **左右镜像**
- ⬜ **去除白底**
- 📝 **文字拼豆**：输入文字生成字符拼豆图
- 📐 **图纸打印**：按豆板尺寸生成 A4 打印图
- 📱 **响应式 UI**：手机 / 平板 / 桌面三档适配

## 🚀 本地使用

直接双击 `index.html`，或：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 📦 部署

### Render（推荐）

`render.yaml` 已配置，连接到 GitHub repo 后自动部署。

### 其他静态托管

任意支持静态文件的 CDN / Hosting 都可：
- Netlify
- Vercel
- Cloudflare Pages
- GitHub Pages

## 🎯 适用场景

- 拼豆手作爱好者：把照片/插画转成拼豆图纸
- 礼物定制：制作专属拼豆作品
- 教学：用色卡和编号学习色彩搭配
